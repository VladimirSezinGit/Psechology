# Продающий лендинг для курса по кинологии «Это база»

![Скриншот проекта](ВСТАВЬ_СЮДА_КАРТИНКУ)

**О проекте:**
Курс для владельцев собак. Нужно было простым языком объяснить ценность и закрыть возражения.

**Что сделано:**

- Сделал аккуратные карточки и списки.
- Обеспечил адаптивность для мобильных устройств.
